# مين أكثر؟ — Game Night

## التشغيل محليًا

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

ثم افتح الرابط الذي يظهر في الطرفية. افتح الرابط نفسه من أجهزة اللاعبين إذا كانت على الشبكة نفسها (مع استخدام عنوان IP لجهاز المضيفة بدل `localhost`).

## دخول المضيفة

- الرمز الافتراضي: `2468`
- لتغييره قبل التشغيل في PowerShell:

```powershell
$env:HOST_PIN="رمز-جديد"
python -m streamlit run app.py
```

## ملاحظات ليلة اللعبة

- جرّبي اللعبة بلاعبين تجريبيين قبل وصول المجموعة.
- اتركي جهاز المضيفة يعمل طوال اللعبة.
- التصويت واللاعبون محفوظون في `game.db`.
- استخدمي زر «تصفير اللعبة» من لوحة المضيفة لبدء جلسة نظيفة.
